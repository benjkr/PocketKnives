PocketKnives · logo concepts

Round two: each mark is a cloth presenting resting pocket knives, one open and one closed, drawn in the same Windows XP Luna plastic as the first two blades: glossy tube shading, Luna blue with Start-button green and amber, steel bolsters, darker same-colour outlines and a soft down-right shadow. Each mark is a single SVG on a 64-unit grid. Every size below, including the 16 px tray and favicon mocks, is that same file. The first round (fan, check, K, pocket, pointer) is in git at a551759.

A canvas tool roll laid open with the pocket knives tucked under its loops. The third loop is empty, waiting for the next blade.

At 16 px: a tan roll with blue and green flecks. The rolled end keeps it recognisable; the knives themselves drop out.
